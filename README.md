# Food Wastage Management System

## Overview
The Food Wastage Management System is a web-based platform designed to reduce food waste by connecting food donors with NGOs, charities, and people in need. The system provides an easy way to donate surplus food, manage requests, and track donations efficiently.

## Features
- User Registration and Login
- Food Donation Management
- Request and Accept Donations
- NGO and Receiver Management
- Admin Dashboard
- Secure Database Management
- Responsive User Interface

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: MySQL

## Objectives
- Reduce food wastage.
- Help distribute surplus food to people in need.
- Provide a simple and efficient donation platform.
- Encourage community participation in reducing hunger.
